# ADR-0003: DELETE типа события возвращает 200 JSON c числом удалённых бронирований

- **Статус:** принято
- **Дата:** 2026-09-01 (обновлено 2026-09-07/08)

## Контекст

При удалении типа события связанные бронирования удаляются каскадно. Нужно было решить, что возвращает API: пустой 204 или тело с результатом.

## Решение

Миграция контракта: `DELETE /api/admin/event-types/{id}` возвращает **200** с телом

```json
{ "deletedBookings": 3 }
```

вместо пустого 204. Требуемый ответ описан в TypeSpec как `EventTypeDeleteResult` и в OpenAPI.

## Последствия

- Админский UI показывает предупреждение о каскадном удалении в модалке подтверждения.
- Обновлено соглашение эмиттера OpenAPI (schema для 200 вместо 204).
- Связано с ADR-0004: контракт правится в TypeSpec, а не напрямую в коде.
