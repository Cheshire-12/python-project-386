# AGENTS.md
Инструкции для ИИ агентов работающих в этом проекте.

## Обзор проекта
Веб-приложение "Календарь звонков": бэкедн выполен на Flask(Python >= 3.12) + SQLite, API контракт записан в 3 файлах: typespec/(main.tsp, models.tsp, operations.tsp)

## Струкрута проекта
Главное правило - фронтенд отдельно, бэкенд отдельно.
